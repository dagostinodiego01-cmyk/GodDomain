# Design

## Pillars (draft — change freely)
1. **Combat feel first.** If a fight is not fun in a grey-box arena, no amount of content will fix it.
2. **Meaningful class progression.** Tiers, promotions and hidden classes give players long-term goals.
3. **A world that supports commerce.** Crafting, trade and (later) city building feed from the same item and class data.
4. **Achievable scope.** Every feature must be buildable by one developer, or it waits.

## Prototype scope: "Starter Village"
- One walkable village with: central square, quest board, class trainer, market stall, crafting row.
- One playable class, **Tier 0 → Tier 1** promotion via a single quest.
- Three or four skills, basic gear, two or three monster ranks plus one mini-boss.
- Single-player experience, built on replication-correct code.

## Inspiration and intellectual property

This game is **inspired by** the VRMMO/LitRPG genre, including a web novel's in-fiction game. The following are **not** to be reused:

- Names of the game, characters, places, factions, gods
- Class names and promotion lines (e.g. any "Sword …" tier titles)
- Specific lore, item names and quest lines

Fair to adapt as **general ideas**: tiered progression, promotion quests, sheltered early game, monster ranks mirroring player tiers, race choice as a mid-game trade-off.
